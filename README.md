Code for running the NHANES exposome-wide association study on epigenetic aging. Full manuscript is available online at [Khodasevich et al 2025](https://www.aging-us.com/article/206201/text)  

"00_NHANES_Dataset_Formation_Upload.RMD" contains code for accessing and compiling NHANES data, primary output is "NHANES_Exposures_Clean.RData"  
"00_NHANES_LODs.RMD" contains code for calculating detection frequencies of exposures, primary output is "NHANES_LODs.csv"  
"01_NHANES_Analysis_Updated.RMD" contains code for running and saving all models.  
"02_NHANES_TablesFigures.RMD" contains code for generating all tables and figures.
